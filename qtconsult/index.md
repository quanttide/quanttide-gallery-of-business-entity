# 量潮咨询

量潮咨询面向企业提供顾问服务，分**创业咨询**与**创新咨询**两类——一类解决人和组织的问题，一类解决系统和效率的问题。两类都从「把客户说不清的真实需求理清楚」开始。

## 创业咨询

面向刚开始创业的人，提供**管理方法上的帮助与辅导**。

初创阶段的典型处境是：业务在长、人越来越多，创始人的压力急剧扩大，工作和生活的边界越来越模糊，感觉公司开始失控。这类问题很少有现成答案，靠的是把创始人和公司的关系重新摆正——比如「创业公司是创始人的伙伴，不是孩子」：它不是需要无限责任哺育的子女，而是和自己一起成长、互相反哺的伙伴。公司进入「青春期」开始有自己的想法，未必是失控，而是它开始有了自己的生命。

服务形式以一对一为主：按客户的目标定制节奏，包含定期战略对话、日常随时咨询、月度经营分析报告。方法论的核心是**帮客户建立自己的「第二大脑」系统**——观察和梳理他手上的系统，把它显性化，让经营者自己看得见全盘。

## 创新咨询

偏技术一侧：通过**数字化升级、智能化改造**帮企业提高效率。典型客户是业务模式在升级、技术体系需要适配、正在做数字化与智能化转型的中小企业。

工作按**调研 → 分析 → 决策 → 执行**推进：

- **调研**：梳理客户的整体状况——技术架构、研发流程、技术团队、业务战略。
- **分析**：判断问题的性质。这类项目多半是「业务模式不断升级、技术体系适配、数字化与智能化转型」的经典问题。
- **决策**：帮客户把该下的决心下掉。例如是同时研发新平台和升级旧平台，还是旧平台升级完再研发新平台；是独立研发新旧平台，还是边重构边融合。决策梳理本身就是交付的一部分。
- **执行**：按既定计划实施。量潮同时具备数据处理、技术教育、企业咨询、平台研发的完整能力，刚好覆盖企业数字化转型需要的能力组合。

工作方法上我们引入 **OODA 循环**（观察—判断—决策—行动）作为「适应环」：客户的想法变化本身就是工作的一部分，不需要因为它而重新谈判——这也是把这类服务做得可预期的方式。

交付形态是**客户能看的看板**：把调研、分析、决策、执行的每一步都列举明白，让客户像看发射控制台一样看到全盘状况，最大限度减少双方摩擦。

## 难点在哪

咨询真正的难点从来不是实施，而是**搞清楚客户说不清的真实需求**——用尽各种办法把复杂状况理清楚。与数据和课堂业务不同（那两条线面对的是高校及其师生，客户素质总体较高、诉求相对清楚），咨询要直接面对一个企业内部的多方利益冲突：规模更大、组织更复杂、连续性更长，需要充分的耐心和细心。这也是我们把流程尽量显性化的原因——先在自己的内部项目上把流程打磨透明，再拿给客户看。
