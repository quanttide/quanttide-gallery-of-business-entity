# 范围

量潮科技产品容器的分工范围：先分清每个容器负责什么，再把产品装进去。这个分工模式对量潮科技所有平台都成立。

## site

site 负责介绍规则，基本不接入服务器。进来先看 site，新人导航这类规则性信息适合上架。

## lite

lite 负责提供信息，接入服务器、动态变化。用户从 site 根据需要进入 lite。

## studio

付费客户（如浙理工）进入 studio，管理用户的学习进度。

## cli

cli 是 AI 的入口：平台内部不一定内置 AI，AI 能力通过 Skill 适配接入。

cli 也是判断自建边界的尺子：外部工具的 cli（如飞书 cli）能批量做的就用它，做不了的批量操作就是自建系统的建设重点。
