# 试用期管理判例

## 判例：技术实习生 PR 质量不达标

**日期**：2026-06-18

**裁决人**：张果

**案情**：技术实习生林漓入职后，PR（Pull Request）质量多次不达标。张果指导后仍无法达到要求。林漓通过同事转达辞职意愿，理由为"能力不足、无人带领、自己掌控不了开发方向"。

**裁决**：不接受辞职，直接辞退。

**裁决理由**：
> 不收 PR 了，直接辞退。他的 PR 就是在浪费我时间。
> 他没有带的价值，我已经带了，但是没有收益。

**判例价值**：
- **不接受辞职，主动辞退**：当员工因能力不足提出辞职时，公司应主动辞退而非被动接受辞职。目的是掌握主动权，防止后续劳动纠纷（辞退可走正式流程，辞职可能被解释为"被迫离职"）
- **带人的边界**：管理者已经投入指导但无收益的，没有继续带的价值。判例确立了一条红线——**管理者投入指导后仍无改善的，及时止损**
- **时间成本优先**：PR 质量差持续消耗管理者时间，这种消耗本身就是终止关系的充分理由

**适用范围**：技术序列实习生的试用期管理

**操作指引**：
1. 发现 PR 质量持续不达标时，先给出明确改进要求和期限
2. 期限内未改善的，直接启动辞退流程（不接受辞职）
3. 辞退时明确告知原因（具体到 PR 质量、时间成本等事实）
