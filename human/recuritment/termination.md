# 试用期管理判例

## 判例：技术实习生交付质量不达标

**案情**：技术实习生入职后，交付质量（如 PR）多次不达标。管理者指导后仍无法达到要求。该实习生提出辞职意愿，理由为能力不足。

**裁决**：接受辞职。

**裁决理由**：员工主动辞职的，公司无法律责任，接受即可。不需要主动辞退。

**判例价值**：
- 员工主动辞职的，接受即可，无需转为辞退流程
- 管理者已投入指导但无改善的，及时止损

**适用范围**：技术序列实习生的试用期管理

**操作指引**：
1. 发现交付质量持续不达标时，先给出明确改进要求和期限
2. 期限内未改善的，评估是否继续留用
3. 员工主动提出辞职的，接受辞职并办理离职手续
